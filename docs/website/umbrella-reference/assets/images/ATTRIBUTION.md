# Asset attribution — CIVOLINK umbrella reference suite

## `assets/images/`

This directory is **intentionally empty**.

The CIVOLINK umbrella reference suite deliberately uses no photographic or
third-party imagery:

- All illustrations are CSS-drawn diagrams (`.diagram`, `.diagram__hub`,
  `.diagram__node`, `.diagram__link`) defined in `assets/css/styles.css`.
- All icons are hand-authored inline SVG paths embedded in each page
  (24×24 viewBox, `stroke: currentColor`, no icon font, no icon package).
- The brand mark in `assets/icons/civolink-mark.svg` is an original geometric
  glyph created for this reference suite.

Consequences:

- No stock photography, no licensed image bundles, no copyrighted brand
  imagery and no remote image URLs are used.
- The suite renders fully offline with zero external requests.

If photographic imagery is introduced later, record the source, licence,
attribution and expiry terms in this file before adding the asset.
