Support routing

Technical support does not run through this page

The umbrella website has no ticket queue. Support is an application-specific responsibility: the product you are using provides its own support route, under its own terms.

For CIVOLINK WIFI

Connectivity and hotspot issues are handled by the Wi-Fi product's own support configuration. That route is defined by the product operator, not by this site.

For Biashara Flow

The product is planned; a support model will be defined alongside its implementation rather than assumed here.

For corporate matters

Use the enquiry form above. It demonstrates the routing; the confirmed channel will be published here once the owner approves it.

Not sure which route fits?

Choose “General enquiry” and describe the situation — misrouted messages are easy to redirect; lost ones are not.
