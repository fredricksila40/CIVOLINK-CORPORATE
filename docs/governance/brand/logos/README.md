# CIVOLINK proposed logo assets

The PNG files in this directory are crops of the supplied composite
presentation board, not editable vector originals. They are proposed assets
pending owner approval and must not automatically replace existing product
or production logos.

The `reference/` subdirectory preserves the original, unmodified composite
PNG supplied in Downloads. The board's variants are raster-only; no matching
editable SVG family was supplied. The separate approved SVG family at
`E:\Documents\VS\CIVOLINK\assets\logo\` has different artwork and was not
copied or substituted for the board variants.

The source board contains four horizontal variants and four standalone
marks. It does not contain a separate stacked logo; none has been created.
The source scale limits the raster crops' resolution; see
[`CIVOLINK_BRAND_GUIDELINES.md`](../../CIVOLINK_BRAND_GUIDELINES.md) §11 for their dimensions and quality
notes.
